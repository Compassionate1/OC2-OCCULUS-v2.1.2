# OC2 v2.0.1 — Booch-inspired architecture package

**RESTRICTED** is a project-defined watermark, **not** a governmental classification.

- `01-domain-object-model.puml`: UML classes, stereotypes, ownership, composition, cardinality, dependencies and explicit implementation boundaries.
- `02-software-architecture.dot`: layered software architecture source.
- `02-software-architecture.svg` / `.png`: rendered architecture diagram, generated with Graphviz.
- `03-runtime-sequence.puml`: simulation, signed export and live preview runtime behavior.
- `04-component-map.mmd`: Mermaid component view (GitHub-renderable).
- `SOURCE-TRACEABILITY.md`: diagram-to-source traceability, invariants and unimplemented integration gaps.

Render PlantUML files using PlantUML locally. No remote rendering is required. Architecture diagram was rendered locally with Graphviz.
