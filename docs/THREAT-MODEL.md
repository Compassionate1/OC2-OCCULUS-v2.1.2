# Threat model
Assets: synthetic event frames, evidence integrity, application identity. Threats: malicious tampering of JSON; substitution of public key + signature; insecure export/share destination; malicious dependencies; misrepresentation of synthetic data as real observation. Mitigations: SHA-256, Ed25519, explicit SYNTHETIC_SIMULATION provenance, no network permissions, no real sensors. Residual: bundled public key does not authenticate signer; recipients must independently pin trusted public key for provenance. iOS Keychain / Secure Enclave-backed signing policy and trusted timestamping are future work.
