# Threat model
Assets: research integrity, reproducibility, CI credentials, source provenance. Trust boundaries: CLI arguments, GitHub PRs, CI dependencies, downloaded ZIP. Risks: misleading accuracy claims, synthetic-to-real domain shift, untrusted code contributions, artifact tampering, supply-chain compromise, dataset leakage. Controls: no network or real sensor inputs; deterministic seeds; trajectory-level holdout; versioned test suite; SHA-256 manifest; least-privilege CI; private repo recommendation. Residual risks: scientific validity unproven, unsigned artifacts, workflow tags not SHA-pinned, incomplete security scanners, and model calibration failures. Do not ingest surveillance, personal, or protected health data.
