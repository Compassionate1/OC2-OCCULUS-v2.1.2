# ADR-0001 — Offline synthetic research baseline
Status: Accepted for v1.0.0 prototype.
Decision: Python 3.10+ standard-library runtime; deterministic seeded independent synthetic trajectories; abstract noisy auditory bearing and occlusion; no device inputs, network access, external datasets or real-world actuation. Holdout split by trajectory ID. Rationale: portable, auditable, reproducible, privacy preserving. Consequences: low external validity, incomplete posterior calibration, no biological validation.
