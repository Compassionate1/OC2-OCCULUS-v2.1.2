# Roadmap beyond v1.0.0
- Multi-hypothesis auditory posterior with front/back and elevation ambiguity.
- Nested group holdout, separate calibration set and pre-registered test scenarios.
- Class-balanced synthetic recognition with ROC/PR, confusion matrices and selective prediction.
- Temporal occlusion bursts, variable visual lighting, correlated acoustic noise and environmental reverberation.
- Sensitivity analysis, Monte Carlo across seeds, threshold optimization on validation only.
- Proper uncertainty calibration, model cards, evidence signing, SBOM, CodeQL and dependency audits.
