# Independent CMMI appraisal readiness charter — draft

**Not commissioned.** Procurement and assessor engagement require explicit authorization.

Scope: organizational unit, representative projects, support functions, governance and historical performance data. Select a qualified independent appraisal lead; establish conflicts-of-interest controls and evidence handling. Examine institutionalization of processes, quantitative performance baselines/models, causal analysis and measurable improvements. Preserve original GitHub workflow logs, approvals, change records, incident tickets, process metrics, and sample selections. Do not infer Level 5 from a custom evidence index or isolated repo.

Deliverables: appraisal scope statement, gap assessment, evidence sufficiency matrix, interview plan, nonconformity log, corrective-action owners, readiness decision, and independent written report.
