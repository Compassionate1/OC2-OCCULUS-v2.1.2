# OC2 security policy

Project-defined RESTRICTED marking is not a legal classification. Live camera is opt-in and local; no recording or network upload. Never publish captured personal images or sensitive location information. Synthetic evidence signatures use ephemeral self-signed keys; do not claim trusted forensic provenance. Review permissions, device security, dependency audit, code-signing and key management before production. Report vulnerabilities privately to repository maintainers; no public reporting contact is configured.
